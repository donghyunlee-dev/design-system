# 배포 전 체크리스트

> 화면을 구현한 뒤, 배포하기 전에 확인하는 Do / Don't 규칙입니다. 심각도가 `높음`인 항목은 반드시 지켜야 합니다.

---

## 접근성 (Accessibility)

| 항목 | Do | Don't | 심각도 |
|---|---|---|---|
| 아이콘 전용 버튼 | `aria-label`로 버튼 목적을 명시 | 아이콘만 두고 텍스트 라벨 생략 | 높음 |
| 폼 입력 라벨 | `FormField label="..."`로 눈에 보이는 라벨 연결 | `placeholder`만으로 라벨 대체 | 높음 |
| 명암비 | 본문 텍스트 대비 4.5:1 이상 유지 (`--color-foreground` / `--color-background` 조합 확인) | 저대비 회색 텍스트를 배경에 바로 사용 | 높음 |
| 포커스 표시 | 키보드 탭 이동 시 포커스 링이 보이도록 유지 | `outline: none`으로 포커스 링 제거 | 높음 |
| 모션 최소화 | `prefers-reduced-motion` 사용자에게는 애니메이션 축소·생략 | 모든 사용자에게 동일한 모션 강제 | 중간 |
| 상태 배지 | 색상 + 텍스트/아이콘을 함께 표시 (`Badge`, `StatusBadge`) | 색상만으로 상태 구분 (색맹 사용자 배제) | 중간 |

---

## 인터랙션 / 모션

| 항목 | Do | Don't | 심각도 |
|---|---|---|---|
| 호버 트랜지션 | `transform`, `opacity`만 애니메이션 (150-300ms) | `width`, `height`, `margin` 등 레이아웃 속성 애니메이션 | 중간 |
| 클릭 가능 요소 | 모든 클릭 요소에 `cursor-pointer` 적용 | 클릭되는데 커서가 기본 화살표로 남음 | 낮음 |
| 로딩 상태 | 비동기 작업 중 `Spinner`/`Skeleton`으로 진행 상태 표시 | 아무 피드백 없이 화면이 멈춘 것처럼 보임 | 높음 |
| 저장/삭제 확인 | 삭제·되돌릴 수 없는 작업은 `Modal`로 확인 후 실행 | 확인 없이 즉시 삭제 | 높음 |
| 결과 알림 | 저장/실패 시 `useToast()`로 결과 안내 | 성공/실패 여부를 사용자가 알 수 없음 | 중간 |

---

## 폼 / 데이터 테이블 (업무 화면 특화)

| 항목 | Do | Don't | 심각도 |
|---|---|---|---|
| 유효성 에러 | `FormField error="..."`로 어떤 값이 왜 틀렸는지 표시 | "입력값을 확인하세요" 같은 모호한 에러 | 높음 |
| 빈 데이터 | 목록이 비었을 때 `EmptyState`로 안내 | 빈 테이블/빈 화면을 그대로 노출 | 중간 |
| 대량 데이터 | 페이지네이션 또는 가상 스크롤 적용 | 수천 건을 한 번에 렌더링 | 높음 |
| 행 클릭 영역 | `onRowClick`으로 행 전체를 클릭 가능하게 | 작은 링크/버튼만 클릭 가능 | 낮음 |

## 반응형 / 테마

| 항목 | Do | Don't | 심각도 |
|---|---|---|---|
| 브레이크포인트 | 375px(모바일) / 768px(태블릿) / 1024px / 1440px 확인 | 데스크톱 해상도에서만 확인 | 중간 |
| 다크 모드 | `tokens/semantic.css`의 다크 모드 토큰으로만 색상 전환 ([TOKENS.md](./TOKENS.md#테마-적용-예시-다크-모드) 참고) | 컴포넌트에 색상 하드코딩 | 높음 |
| 사이드바 | 좁은 화면에서 `Sidebar`가 접히거나 `Drawer`로 전환 | 좁은 화면에서 사이드바가 콘텐츠를 가림 | 중간 |
