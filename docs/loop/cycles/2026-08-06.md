## 오늘의 스코프

오늘은 `docs/loop/backlog.md`에 status가 "대기"이면서 source가 `human-added` 또는 `eval-found`인 항목이 없어(B001~B013 모두 "완료" 상태), 정책 7항에 따라 `docs/loop/benchmark-suite.md`의 고정 목록을 cursor 순서대로 소비합니다. 현재 cursor 값은 8이므로 0-based 인덱스 8에 해당하는 **BM09 — Asana 템플릿 갤러리** (https://asana.com/templates, 패턴: 카드 그리드/템플릿)를 오늘의 벤치마크로 선택했습니다.

Asana 템플릿 갤러리는 업무 목적별 템플릿(프로젝트·워크플로우)을 카테고리 사이드바 또는 필터와 함께 썸네일 카드 그리드로 진열하고, 카드별 미리보기·설명·사용 시작 CTA를 노출하는 외부 서비스형(`service`) 갤러리 패턴입니다. 재현·평가 단계에서 기존 `src/templates/`의 카드 그리드/갤러리 계열(예: TemplateGallery, TemplateGalleryMedia, Trello·Notion·Figma 계열 재현 결과)과 대조해, 정책 2항(중복 금지)·PATTERNS.md 기준에 따라 목적이 겹치는 신규 템플릿은 추가하지 않고, 구조적으로 비어 있는 갭(design-system-gap)만 승격 후보로 삼습니다. 정책 3항에 따라 이 페이지가 외부 서비스형(`service`) 축인 점을 유의해, 사내 기간계 축과 뒤섞지 않습니다.

선택 처리 후 benchmark-suite의 cursor 값을 (8 + 1) % 10 = **9**로 갱신했습니다(다음 사이클은 BM10 Basecamp 기능 소개).

## 완성도 평가

- 벤치마크: Asana 템플릿 갤러리 (https://asana.com/templates)
- 오늘 구현한 스토리: title `Templates/Service/Catalog`, export `ServiceRequestCatalog` (id: `templates-service-catalog--service-request-catalog`)
- 자사 스크린샷: `docs/loop/screenshots/2026-08-06-ours.png`
- 벤치마크 스크린샷: 조직 네트워크 정책이 `asana.com`에 대한 아웃바운드 HTTPS CONNECT를 403으로 차단하여 캡처하지 못했습니다(에이전트 프록시가 정책 거부를 반환, 재시도하지 않음). 따라서 이번 사이클은 학습된 일반 지식상의 Asana 템플릿 갤러리 구조(히어로 검색 + 카테고리 필터 + 카드 그리드 + 카드별 미리보기 이미지)와 자사 구현을 대조해 평가했으며, 스코어 신뢰도는 이미지 대비 방식보다 낮습니다.

### 갭 목록

1. **componentFidelity 저하 원인** — `src/components/data/MediaCard.tsx`는 `coverSrc` 미지정 시 단순 `bg-surface-overlay` 박스에 `coverFallback`만 표시하도록 되어 있고, `ServiceCatalog.tsx`의 목데이터도 `thumbnailSrc`를 전혀 채우지 않아 커버 영역이 대부분 비어 보임. `MediaCard`는 `coverSrc` prop을 이미 지원하므로 컴포넌트 자체는 문제가 없고 이번 구현에서 활용하지 않은 것.
   - 분류: `execution-issue`
2. **interaction 저하 원인** — `src/components/navigation/ChipGroup.tsx`가 정확히 이 용도(단일 선택 필터, `role="tablist"`/`aria-selected`)로 이미 존재하는데, `ServiceCatalog.tsx`는 152~178행에서 직접 `<button>` 마크업과 커스텀 클래스로 카테고리 필터를 재구현해 접근성 롤과 시스템 표준 상태 스타일을 놓침.
   - 분류: `execution-issue`

두 갭 모두 `src/components`에 상응하는 컴포넌트/패턴이 이미 존재함을 확인했으므로(위 파일 경로 참조), design-system-gap으로 승격하지 않습니다. 대신 `ServiceCatalog.tsx`에서 `ChipGroup` 사용 및 대표 카드에 `thumbnailSrc` 제공으로 수정하는 execution-issue로 기록합니다.
