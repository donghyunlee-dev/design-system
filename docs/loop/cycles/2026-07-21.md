### 벤치마크 접속 불가 (재시도 없음)

Playwright로 `https://docs.stripe.com` 접속을 시도했으나 `net::ERR_TUNNEL_CONNECTION_FAILED`로 실패했습니다. `curl -sS "$HTTPS_PROXY/__agentproxy/status"` 확인 결과 `docs.stripe.com:443`에 대해 `connect_rejected`(게이트웨이 403, 정책 차단)가 기록되어 있어 조직 네트워크 정책상 차단된 도메인임을 확인했습니다. 2026-07-16 사이클에서도 동일한 유형의 외부 도메인 차단이 있었고, 그때의 원칙(정책 차단은 재시도하지 않고 사실만 기록)을 그대로 따라 재시도하지 않았습니다. 따라서 `docs/loop/screenshots/2026-07-21-benchmark.png` 파일은 생성하지 않았고, 아래 점수는 벤치마크 실제 화면과의 시각적 대조가 아니라 Stripe Docs 홈에 대한 사전 지식(좌측 네비게이션 트리 + 검색창 + 카드형 가이드 그리드 + 우측 보조 정보 레이아웃)에 근거한 참고용 평가입니다. 정확한 점수는 접근 가능한 환경에서 재검증이 필요합니다.

### 갭 목록

1. **interaction — Cmd/Ctrl+K 스타일 커맨드 팔레트·검색 오버레이 부재 (design-system-gap)**: `src/components`, `src/templates` 전체를 검색(`Command`, `Palette`, `Cmd+K`, `⌘` 키워드)했으나 관련 컴포넌트가 전혀 없습니다. Stripe Docs 홈처럼 상단 검색창을 눌렀을 때 오버레이로 뜨는 커맨드 팔레트/즉시검색 패턴에 대응하는 컴포넌트나 패턴이 시스템에 아예 없어 이번 구현(`DocsHub.tsx`)도 `Input` 컴포넌트로 정적 검색창만 배치했습니다.
2. **interaction — 좌측 네비게이션의 활성 상태만 있고 인터랙션 다양성 부족 (execution-issue)**: `DocsHub.tsx`는 `activeItemId` 하나로 강조 스타일만 적용하며, 이미 시스템에 존재하는 `Sidebar`(`src/components/navigation/Sidebar.tsx`) 컴포넌트를 사용하지 않고 자체 목록을 렌더링합니다. `Sidebar` 컴포넌트가 이미 존재하므로 이는 컴포넌트 부재가 아니라 이번 구현에서 기존 컴포넌트를 재사용하지 않은 실행 이슈입니다.
3. **typography — 카드 내부 여백이 다소 조밀함 (execution-issue)**: `Grid`, `Card` 컴포넌트 자체의 spacing 토큰은 존재하고 다른 템플릿(예: Dashboard, DocCatalog)에서는 더 넉넉한 gap을 사용하는 사례가 있어, 토큰 부재가 아니라 이번 스토리에서 상대적으로 좁은 gap 값을 선택한 실행 이슈로 판단됩니다.

### 일관성 위반으로 시스템 변경 보류 — 사람 판단 필요

Consistency Check 결과, 이번 사이클 범위(`loop/2026-07-21-stripe-docs`, CommandPalette/DocsHub 추가)와 무관하게 2026-07-14 이전부터 존재하던 기존 컴포넌트 파일 `src/templates/business/DataImportWizard.tsx`가 대폭 재작성되어 정책 9항(기존 컴포넌트의 시각적 결과를 바꾸는 변경 금지) 위반으로 판정되었습니다. props 시그니처가 전면 교체되고(`fileName`/`onUpload`/`targetFieldOptions`/`mapping`/`onMappingChange`/`summary` 등 제거 → `mappings`/`onFileChange`/`onNext`/`onPrev`/`nextLabel`/`commitProgress` 등으로 대체), `Select`·`Alert` 컴포넌트가 제거되고 `Progress` 컴포넌트로 대체되었으며, 4단계 완료 화면의 요약(summary) 표시 구조도 삭제되어 기존 컴포넌트의 API와 시각적 결과가 모두 바뀌었습니다. 파생 영향으로 `src/stories/templates/Business.stories.tsx`의 `Import` 스토리 삭제 및 관련 타입 import 제거도 함께 발생했습니다.

이에 따라 `DataImportWizard.tsx`와 `Business.stories.tsx`의 관련 변경을 원래 상태로 되돌렸습니다. 아울러 이번 사이클에서 새로 추가된 `CommandPalette` 컴포넌트(및 스토리, `src/index.ts` export)는 그 자체로 하드코딩된 색상/spacing/shadow나 이질적 스타일링은 없었으나, "Cmd/Ctrl+K 커맨드 팔레트" design-system-gap을 이번 사이클에서 해결하지 않고 미해결 상태로 남기기로 함에 따라 함께 제거했습니다. `DocsHome` 스토리는 정상 동작을 유지하기 위해 검색 UI를 기존 `Input` 컴포넌트를 사용하는 정적 검색창으로 대체해 재구현했습니다. 커맨드 팔레트 관련 design-system-gap은 `docs/loop/backlog.md`의 B011 항목으로 등록해 사람 판단이 필요한 대기 상태로 남겼습니다.
