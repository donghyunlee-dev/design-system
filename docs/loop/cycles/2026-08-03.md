## 오늘의 스코프

오늘은 `docs/loop/backlog.md`에 status가 "대기"이면서 source가 `human-added` 또는 `eval-found`인 항목이 없어(B001~B011 모두 "완료" 상태), 정책 7항에 따라 `docs/loop/benchmark-suite.md`의 고정 목록을 cursor 순서대로 소비합니다. 현재 cursor 값은 5이므로 0-based 인덱스 5에 해당하는 **BM06 — Zendesk Help Center** (https://support.zendesk.com/hc/en-us, 패턴: 문서/FAQ)를 오늘의 벤치마크로 선택했습니다.

Zendesk Help Center는 카테고리·섹션 계층으로 도움말 문서를 분류하고, 상단 검색과 인기 문서·카테고리 카드로 진입점을 제공하는 문서/FAQ 성격의 지식베이스 패턴입니다. 재현·평가 단계에서 기존 `src/templates/`의 문서/네비게이션 계열(예: DocumentCatalog, DocsHub 등 Stripe 계열 재현 결과)과 대조해, 목적이 겹치지 않는 구조적 갭(design-system-gap)만 승격 후보로 삼습니다.

선택 처리 후 benchmark-suite의 cursor 값을 (5 + 1) % 10 = **6**으로 갱신했습니다(다음 사이클은 BM07 Figma Community 홈).

### 갭 목록

1. **TOC 스크롤 하이라이트 부재** (execution-issue) — 우측 "이 문서에서" 목차가 앵커 링크만 제공하고, 스크롤에 따른 active 상태 강조가 없습니다. `src/templates/business/SettingsPage.tsx` 등에 클릭 기반 `active` 상태 하이라이트 패턴이 이미 존재해, 유사한 상태 관리 방식을 재사용할 수 있었는데 이번 구현에서 적용하지 않았습니다.
2. **상단 지속 검색바 미재사용** (execution-issue) — `src/templates/business/HelpCenter.tsx`(도움말 센터 홈)에는 이미 검색 Input 패턴이 있으나, `HelpArticleView`에는 재사용되지 않아 상세 페이지에서 바로 검색할 수 없습니다. `src/components`에 검색 입력 요소가 이미 있으므로 구조적 부재가 아닙니다.
3. **하단 "추가 문의" CTA 미재사용** (execution-issue) — `HelpCenter` 홈의 `contactChannels` 카드 패턴이 상세 페이지 하단에는 반영되지 않았습니다. Card 컴포넌트 재사용만으로 표현 가능해 execution-issue로 분류합니다.

`src/components`, `src/templates`를 확인한 결과 위 3건 모두 상응하는 컴포넌트/패턴이 이미 존재해 design-system-gap은 발견되지 않았습니다. 정책 8항에 따라 시스템 변경(컴포넌트/토큰 추가)은 진행하지 않고 본 리포트에만 기록합니다.
