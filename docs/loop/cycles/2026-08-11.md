## 오늘의 스코프

`docs/loop/backlog.md`에 status가 "대기"이면서 source가 `human-added` 또는 `eval-found`인 항목이 없어(B001~B013 모두 "완료" 상태), 정책 7항에 따라 `docs/loop/benchmark-suite.md`의 고정 목록을 cursor 순서대로 소비합니다.

현재 cursor 값은 0이고 표에 10개 행(BM01~BM10)이 있으므로, 0-based 인덱스 0번째 행인 **BM01 — Stripe Docs 홈**(https://docs.stripe.com, 패턴: 문서/네비게이션)을 오늘의 벤치마크로 선택했습니다. 직전 사이클(2026-08-07)에 목록을 한 바퀴 순회하여 cursor가 0으로 순환했으므로, 이번 사이클부터 BM01로 회귀 순회를 시작합니다(policy 7항, 회귀 테스트).

선택 처리 후 cursor 값을 (0 + 1) % 10 = **1**로 갱신했습니다(다음 사이클은 BM02 GitHub Issues 리스트).

정책(policy 3항)에 따라 이 페이지가 기간계(business/admin)와 일반 웹사이트(service) 중 어느 축에 해당하는지 먼저 판단하고, 해당 축에서 기존 컴포넌트/템플릿과 겹치지 않는 구조적 갭(design-system-gap)만 채택합니다. Stripe Docs 홈은 좌측 네비게이션 + 본문 문서 + 우측 목차(TOC)로 구성된 문서/네비게이션 패턴이며, 개발자·내부 사용자용 문서 열람 성격이 강해 기간계(business) 축을 기준으로 재현·평가합니다. 재현 시 기존 문서/카탈로그 계열(DocumentCatalog, DocsHub 등)과 대조해 정책 2항(중복 금지)에 따라 목적이 겹치는 신규 템플릿은 추가하지 않습니다.

**재현 스토리**: `Templates/Business` / export `DocsHome` (Storybook id: `templates-business--docs-home`, 표시명 "Docs Hub")

**스크린샷**
- 자사: `docs/loop/screenshots/2026-08-11-ours.png`
- 벤치마크: 캡처 실패 — 에이전트 프록시가 `docs.stripe.com:443`에 대한 CONNECT 요청을 조직 egress 정책으로 403 차단함(`connect_rejected`, policy denial). 재시도/우회를 시도하지 않고 보고함. 아래 점수는 학습된 지식상의 Stripe Docs 홈 레이아웃(상단 검색, 카테고리별 좌측 네비게이션, 인기 가이드 카드 그리드, 우측 바로가기/공지 패널 구성)에 대한 기억에 기반한 것이며, 실제 스크린샷 대비 검증은 아니므로 향후 사이클에서 재검증이 필요함.
