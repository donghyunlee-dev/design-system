## 오늘의 스코프

오늘 사이클 시작 시점 백로그에는 status가 "대기"인 항목이 없었습니다(B001~B007 모두 완료). 따라서 정책 5항 및 태스크 5단계, 그리고 직전 2026-07-11·2026-07-13 사이클의 선례에 따라 기존 `src/components`, `src/templates` 커버리지 갭을 분석해 신규 pm-proposed 항목 3개를 백로그에 먼저 등록한 뒤 일일 스코프 상한(1~3개) 내에서 모두 진행합니다.

선정한 항목:

- **B008 — Data Import / Bulk Upload 템플릿 (데이터 가져오기·일괄 업로드)**: 파일 업로드 → 컬럼 매핑 → 유효성 검증 미리보기 → 반영 결과의 일괄 데이터 적재 흐름이 부재. ERP(Enterprise Resource Planning)·OMS(Order Management System)·WMS(Warehouse Management System) 마스터 데이터(품목·거래처·재고) 일괄 적재에 재활용도가 가장 높다고 판단해 최우선 선정. WizardForm(범용 다단계 폼)·FileExplorer(기존 파일 탐색·관리)와 목적이 명확히 구분됩니다(데이터 인제스천).
- **B009 — Role & Permission Matrix 템플릿 (역할·권한 관리 매트릭스)**: 역할 × 리소스·기능 격자에 권한을 토글로 부여·회수하는 접근제어 관리 레이아웃이 부재. ERP·그룹웨어·PRM(Partner Management System) 등 사내 시스템 공통의 권한 관리 화면에 재활용도가 높음. SettingsPage(키-값 설정 섹션)와 달리 다차원 권한 매트릭스 편집이 목적이라 중복이 없습니다.
- **B010 — Empty / Error State 템플릿 (빈 상태·오류 상태 페이지)**: 무데이터(no-data)·권한없음(403)·페이지없음(404)·서버오류(500) 등 표준 빈 상태·오류 상태 페이지 세트가 부재. 모든 사내 업무 시스템 화면에 공통 적용되는 기반 패턴으로 일관성 확보 가치가 높다고 판단해 선정.

공통 근거:

- 세 항목 모두 기존 `src/templates/business/`(타임라인·승인·대시보드·상세·문서카탈로그·파일탐색기·등록폼·통합검색·인박스·칸반·목록검색·마스터디테일·모니터링·리포트·일정·설정·마법사폼) 및 `admin`/`service` 템플릿과 목적이 겹치지 않아 정책 2항(DRY)에 위배되지 않습니다.
- 세 항목 모두 기존 디자인 토큰과 컴포넌트(Upload, Stepper, Table, Checkbox, Switch, StatusBadge, Alert, Tag, Badge, EmptyState, Button, Card, Stack 등)만으로 재구현 가능하여 정책 4항(신규 의존성 금지)을 준수합니다.
- 세 항목 모두 소비자용 마케팅 트렌드가 아닌 내부 업무 시스템 패턴이라 정책 3항(적합성)에 부합합니다.

## 품질 비교

Storybook을 로컬(포트 6006)에 띄운 뒤 Playwright로 각 스토리를 캡처했습니다. 다만 이번 실행 환경에서는 조직 네트워크 정책상 외부 아웃바운드 HTTPS가 GitHub 관련 일부 도메인(github.com, api.github.com 등)으로만 제한되어 있고, `flatfile.com`, `docs.github.com`, `dribbble.com`은 프록시 단계에서 `403 policy denial`로 차단되어 실제 벤치마크 사이트 화면을 캡처할 수 없었습니다(`curl -sS http://127.0.0.1:46843/__agentproxy/status`로 확인, `connect_rejected` 기록). 정책 6항의 "조직 정책 거부는 재시도하지 않고 보고한다" 원칙에 따라 재시도 대신 이 사실을 명시적으로 기록합니다. 벤치마크 스크린샷 파일에는 Playwright가 실제로 캡처한 접속 실패(`ERR_TUNNEL_CONNECTION_FAILED`) 화면이 저장되어 있으며, 벤치마크 사이트의 실제 UI를 담은 것이 아니므로 아래 소견은 이번 사이클에서는 시각적 대조 없이 사전에 파악한 벤치마크 사이트의 공개 정보(레이아웃 특징에 대한 기존 지식)에 근거한 참고용 서술에 한정합니다. 정확한 시각적 비교는 외부 도메인 접근이 허용되는 환경에서 재수행이 필요합니다.
