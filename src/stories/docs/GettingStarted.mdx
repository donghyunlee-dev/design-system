# Getting Started

## 1. 설치

`@windsoft/ui`는 WindSoft 디자인 시스템 npm 패키지입니다. `0.2.0`부터 React 19를, `0.3.0`부터 Tailwind CSS 4.3.3을 지원합니다.

```bash
npm install @windsoft/ui@0.3.1
npm install -D tailwindcss@4.3.3 @tailwindcss/vite@4.3.3
```

## 2. Tailwind 설정

`vite.config.ts`:

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({ plugins: [react(), tailwindcss()] })
```

WindSoft 글로벌 CSS가 preset(`@config`)과 패키지 컴포넌트 소스(`@source`)를 연결합니다.
`max-w-sm/md/lg`는 Tailwind 기본 컨테이너 폭을 사용합니다. 간격 토큰은 `p-[var(--spacing-sm)]`처럼 CSS 변수로 참조하세요.

## 3. 글로벌 CSS 가져오기

`src/main.tsx`:

```tsx
import '@windsoft/ui/global.css'
```

## 4. 첫 페이지 완성 (5분)

```tsx
import { LoginSimple } from '@windsoft/ui'

export default function App() {
  return (
    <LoginSimple
      logo={<span className="text-2xl font-bold text-brand">내 서비스</span>}
      onLogin={(email, password) => console.log(email, password)}
      onSignup={() => {}}
    />
  )
}
```

## 5. AI 바이브코딩에서 활용

Claude Code 프로젝트에 `CLAUDE.md` 추가:

```markdown
# CLAUDE.md
UI 컴포넌트는 @windsoft/ui 디자인 시스템을 사용한다.
템플릿이 있으면 템플릿을 우선 사용한다.
커스텀 색상은 CSS Variables(var(--color-brand) 등)로 참조한다.
```

## 6. MCP로 디자인 시스템 연결

MCP는 AI 에이전트가 컴포넌트·토큰·업무 템플릿을 검색하는 조회 채널입니다. 화면에서 컴포넌트를 실제로 사용하려면 위의 `@windsoft/ui` 패키지도 설치해야 합니다.

> 현재 운영 MCP에는 별도 인증이 없습니다. 사내 프로젝트에서만 사용하고 외부 고객 서비스에는 연결하지 마세요.

Claude Code를 사용할 프로젝트 디렉터리에서 한 번 등록합니다.

```bash
claude mcp add windsoft-ds --transport http https://windsoft-design-system.vercel.app/api/mcp
claude mcp list
```

연결 후에는 에이전트에게 자연어로 요청할 수 있습니다.

```text
WindSoft 디자인 시스템에서 검색 필터에 적합한 컴포넌트를 찾아 사용 예시를 보여줘.
다크 모드 semantic 토큰을 조회해줘.
주문 목록에 사용할 업무 템플릿을 찾아줘.
```

```text
MCP 연결 → 컴포넌트·템플릿 검색 → @windsoft/ui import → 서비스 화면 구현
```

Postman 호출, 전체 도구 목록, 로컬 서버 설정은 <a href="/?path=/docs/docs-mcp-guide--docs" target="_top">MCP Guide</a>에서 확인하세요.
