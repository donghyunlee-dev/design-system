# SFOOD Design System

에쓰푸드 AI 바이브코딩 프로젝트를 위한 컴포넌트 라이브러리입니다.

## 구조

디자인 시스템은 3개의 레이어로 구성됩니다.

```
토큰 (CSS Variables)
  ↓
컴포넌트 (Button, Input, Card ...)
  ↓
템플릿 (LoginPage, DashboardFull ...)
```
