## 커스터마이징

모든 템플릿은 세 가지 방법으로 수정 가능합니다.

**1. Props로 데이터 주입 (가장 간단)**
```tsx
<DashboardFull stats={myStats} mainChart={<MyChart />} />
```

**2. 슬롯(ReactNode)으로 컴포넌트 교체**
```tsx
<LoginSplit logo={<MyLogo />} />
```

**3. className으로 스타일 오버라이드**
```tsx
<LandingCentered className="bg-white" />
```
