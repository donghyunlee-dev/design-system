# Template Guide

템플릿 메뉴는 사용자가 만들 화면과 수행할 일에 맞춰 구성합니다. `service`, `admin`, `business` 출처를 알 필요 없이 아래 카테고리에서 찾으면 됩니다.

`LandingCentered` · `LandingMinimal` · `LandingSplit` · `FeatureShowcase`

## Account

`LoginSimple` · `LoginSplit` · `SignupPage` · `SettingsSidebar` · `SettingsTabs`

## 선택할 때 비교할 점

- `DataTablePage`는 단순 목록 구성이고, `ListSearchTable`은 제어형 검색·필터·페이지 처리가 포함된 업무 목록입니다.
- `DataFormPage`는 밀도 높은 기본 입력 레이아웃이고, `FormRegister`는 설명과 액션이 많은 카드형 섹션 폼입니다. 여러 단계 진행은 `WizardForm`을 사용합니다.
- `DashboardFull`이 통합 대시보드 기준 구현입니다. `DashboardStats`는 기존 API 호환 어댑터입니다. 운영 상태 추적은 `MonitoringBoard` 또는 `SystemStatusBoard`, 정적 보고는 `ReportLayout`을 선택합니다.
- `GlobalSearchResults`는 유형별 통합 결과, `EntitySearchExplorer`는 엔터티 탭·패싯 기반 탐색, `FacetedSearchResults`는 조건 조합, `TabbedSearchResults`는 범위 전환 검색에 사용합니다.
- `TemplateGallery`는 업무 템플릿 검색용이고 `TemplateGalleryMedia`는 추천 콘텐츠와 작가·사용량 정보가 중심인 미디어 카탈로그입니다. 각 갤러리 변형은 목록/미리보기/큐레이션 흐름을 기준으로 고릅니다.
- 권한 관리에는 `RolesPermissionsMatrix`를 사용합니다. `PermissionMatrix`는 제거된 비공개 중복 구현입니다.

## 커스터마이징

모든 템플릿은 props로 데이터를 주입하고, `ReactNode` 슬롯으로 필요한 요소를 바꾸며, `className`으로 화면에 맞춰 스타일을 조정할 수 있습니다.

```tsx
import { DashboardFull } from '@windsoft/ui'

<DashboardFull stats={myStats} mainChart={<MyChart />} />
```
